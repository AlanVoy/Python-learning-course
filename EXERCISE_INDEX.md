## Задание №52: валидатор времени

- Формат `HH:MM`, 5 символов, двоеточие на третьей позиции, часы 00–23, минуты 00–59.
- **Принято по 15/15 пользовательским тестам** (включая пустой ввод, неправильные разделители, длину и границы).
- Особенность: `.isdigit()` принимает часть Unicode-символов, которые `int()` может не преобразовать; этот случай не закрыт.
- Наличие `lessons/lesson_52.py` в GitHub `main` подтверждено отдельно от результатов тестирования.
