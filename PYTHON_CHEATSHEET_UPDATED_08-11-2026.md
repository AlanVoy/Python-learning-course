## 2. Базовый синтаксис и типы

### 2.1. Ввод, вывод, преобразование типов


**`print(*values, sep=" ", end="\n")` — вывод на экран (практиковали).** В скобках указывают одно или несколько значений через запятую. По умолчанию между ними ставится пробел (`sep=" "`), а в конце — перевод строки (`end="\n"`). `sep` и `end` задаются именованными аргументами. Например:

```python
position = 3
print("Позиция", position, ":", sep="")  # Позиция3:
print("Позиция ", position, ":", sep="")  # Позиция 3:
print("Готово", end="!")                  # Готово!
```

**`input(prompt)` — ввод (практиковали).** Выводит необязательную подсказку и ожидает ввод пользователя. Результат **всегда `str`**, даже если введено `123`. Пример: `name = input("Имя: ")`.

**`int(value)` — преобразование в целое число (практиковали).** `int("25")` даёт `25`; `int("-3")` даёт `-3`. `int("2.5")` и `int("привет")` вызывают `ValueError`. `int(2.9)` даёт `2` (отбрасывает дробную часть по направлению к нулю). Для чтения числа: `age = int(input("Возраст: "))`.

**`str(value)` — преобразование в строку (практиковали).** Например, `str(25)` даёт `"25"`. Нужно, если соединяем число с текстом оператором `+`: `"Возраст: " + str(age)`.

**`type(value)` — тип объекта (практиковали).** `type(25)` — `<class 'int'>`, `type("25")` — `<class 'str'>`. Полезно при отладке; `type(x)` не преобразует значение.

**`list(iterable)` — создать список из перебираемого объекта (ознакомились).** `list(map(int, ["1", "2"]))` даёт `[1, 2]`; `list("кот")` даёт `['к', 'о', 'т']`. Список — отдельная структура данных, которую будем изучать подробно позже.


### 2.2. Переменные и арифметика


**`name = value` — присваивание (практиковали).** Запоминает ссылку на значение под именем `name`. `x = 10`, затем `x = 20` заменяет прежнее значение имени; `=` не сравнивает значения.

**`+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=` — составные присваивания.** `x += 3` означает увеличение `x` на 3; `x *= 2` — умножение на 2. С числами работали неоднократно. Со строками `text += "!"` соединяет строки; `text += 3` вызовет `TypeError`.

**`del name` — удаление имени (разобрали).** После `x = 5; del x` обращение к `x` вызовет `NameError`, если имя не было создано заново. Можно `del a, b`. Обычно вручную удалять локальные переменные не требуется; `del` не гарантирует немедленного освобождения памяти.

**Числовые операторы (практиковали):** `+` сумма, `-` разность, `*` произведение, `/` обычное деление (результат `float`), `//` деление с округлением вниз, `%` остаток, `**` степень. Например, `-7 // 2 == -4` (не `-3`), `-7 % 2 == 1`. Деление на ноль (`/`, `//`, `%`) вызывает `ZeroDivisionError`. Скобки `()` управляют порядком действий.

**`abs(number)` — модуль числа (практиковали).** `abs(-15)` даёт `15`; `abs(15)` — `15`. Часто нужен для обработки цифр отрицательного целого числа без учёта знака.

**`min(...)` и `max(...)` — минимум и максимум (практиковали / разобрали).** Можно передать несколько отдельных значений (`min(3, -1, 8)`) или одну непустую коллекцию (`max([3, 8, 1])`). Сравнение строк — лексикографическое, а не числовое: `min("9", "10")` не является поиском минимального числа. Для пустого списка `min([])` возникает `ValueError`; `min([], default=0)` вернёт `0`. Для чисел из строки сначала требуется преобразование в `int`.


## 3. Условия, циклы и управление

### 3.1. Ветвления, сравнения, логика, циклы


**`if condition:` / `elif condition:` / `else:` — ветвление (практиковали).** `if` проверяет первое условие; `elif` — следующее, если предыдущие ложны; `else` выполняется, если ни одно условие не подошло. `elif` и `else` не могут стоять сами по себе без соответствующего `if`; у `else` нет условия. После `:` идёт блок с одинаковым отступом (обычно 4 пробела).

**Сравнения:** `==` равно, `!=` не равно, `<` меньше, `<=` не больше, `>` больше, `>=` не меньше. Результат — `True` или `False`. Например, `3 <= 5` → `True`. Цепочка `0 <= age <= 120` проверяет обе границы.

**Логика:** `and` требует истинности обоих условий; `or` — хотя бы одного; `not` меняет истинность на противоположную. Например, `age >= 18 and age < 65`. Выражения `and`/`or` вычисляются с сокращением: если результат уже определён, правая часть может не вычисляться.

**`while condition:` — цикл по условию (практиковали).** Перед каждым повтором проверяет условие. Если оно сразу ложно, тело не выполняется ни разу. При счётчике не забывайте менять его, иначе возможен бесконечный цикл:

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

**`for variable in iterable:` — перебор (изучаем, тема не закрыта).** На каждой итерации присваивает переменной очередной элемент. В `for i in range(3):` значения `i`: 0, 1, 2. Изменение `i` внутри цикла не меняет следующий элемент `range()`. После цикла переменная обычно содержит последнее присвоенное значение. Если итераций не было, новое имя не появится.

**`range(stop)` / `range(start, stop[, step])` — диапазон целых чисел (изучаем).** Начало включено, конец исключён. `range(2, 7, 2)` даёт 2, 4, 6. `range(5)` даёт 0–4. `range(5, 0, -2)` даёт 5, 3, 1. Шаг `0` запрещён (`ValueError`). `range` сам по себе не список, но его можно перебирать в `for`.

**`break` — выйти из ближайшего цикла (практиковали).** Работает в `while` и `for`; при вложенных циклах завершает только внутренний. **`continue` — перейти к следующей итерации** (разобрали): пропускает оставшуюся часть тела цикла; в `while` важно не забывать обновлять условие завершения.

**`import sys` и `sys.exit()` — завершение скрипта (разобрали).** Сначала импортируют модуль `sys`, затем вызывают `sys.exit()` при необходимости. Это вызывает `SystemExit`; при обычном запуске скрипт завершается, если исключение не перехвачено. `break` в отличие от него завершает только цикл. Встроенный `exit()` встречался в коде, но для скриптов лучше `sys.exit()`.


### 3.2. Типовые конструкции

```python
if age < 0:
    print("Ошибка")
elif age >= 18:
    print("Взрослый")
else:
    print("Несовершеннолетний")

for i in range(2, 10, 2):
    print(i)  # 2, 4, 6, 8
```

`range(start, stop, step)`: начало включено, конец не включён. `break` выходит из ближайшего цикла, `continue` пропускает остаток текущей итерации. `sys.exit()` завершает скрипт (если `SystemExit` не перехвачено).

## 4. Строки и коллекции

### 4.1. Строки и форматирование


**`len(value)` — длина (практиковали).** `len("кот")` даёт `3`; `len("a b")` даёт `3`, потому что пробел тоже символ. Работает также со списками и другими коллекциями; не работает непосредственно с `int`.

**`text.upper()` / `text.lower()` — регистр (практиковали).** Возвращают новую строку с верхним/нижним регистром: `"PyThOn".lower()` → `"python"`. Исходная строка не меняется, если не присвоить результат: `text = text.lower()`.

**`text.split(sep=None, maxsplit=-1)` — разбить строку (ознакомились).** Без аргументов разбивает по любым последовательностям пробельных символов и не создаёт пустые элементы на краях: `"  10   20  ".split()` → `["10", "20"]`. С явным разделителем: `"a,b,c".split(",")` → `["a", "b", "c"]`. `"a  b".split(" ")` → `["a", "", "b"]`: повторные пробелы здесь дают пустой элемент. `maxsplit=1` ограничивает количество разделений: `"a b c".split(maxsplit=1)` → `["a", "b c"]`. Результат — **список строк**, а не чисел.

**`text.replace(old, new, count=-1)` — заменить подстроку (разобрали).** `"a b c".replace(" ", "")` → `"abc"`; `"кот-кот".replace("кот", "пёс", 1)` → `"пёс-кот"`. Возвращает новую строку, не изменяя исходную. Если требуется убрать обычные пробелы, `replace(" ", "")` удалит именно их, а не все виды пробельных символов.

**`text.find(sub, start=0, end=...)` — найти позицию подстроки (разобрали).** `"12 345 67".find(" ", 3)` → `6`. Индексация начинается с нуля; `start` включается, `end` (если указан) исключается. Если совпадение не найдено, возвращает `-1`. Для поиска после определённой позиции: `text.find(" ", position + 1)`. Метод ищет **символы**, а не числовые значения.

**`f"...{expression}..."` — f-строка (разобрали).** Подставляет результат выражения внутрь текста: `position = 3; print(f"Число на позиции {position}:")` → `Число на позиции 3:`. Пробелы пишутся вручную там, где нужны. Можно вставлять выражения: `f"Сумма: {2 + 3}"`. Для буквальных фигурных скобок пишут `{{` и `}}`.

**`a + b` и `text += suffix` — соединение строк (практиковали / разобрали).** `"Привет" + "!"` → `"Привет!"`; `text += "!"` присваивает переменной новую соединённую строку. Строки неизменяемые; операторы не редактируют символы внутри прежнего объекта.


### 4.2. Индексация, `.isdigit()`, `.strip()`, сравнения


**`text[index]` — доступ к символу (разобрали).** Индексы начинаются с нуля: `"кот"[0]` → `"к"`, `"кот"[2]` → `"т"`. Отрицательный индекс отсчитывает с конца: `"кот"[-1]` → `"т"`. Если индекс выходит за пределы строки, возникает `IndexError`. Строки неизменяемы: `text[0] = "К"` недопустимо.

**`a == b` / `a != b` — сравнение строк и символов (разобрали).** `"кот" == "кот"` → `True`, `"кот" == "Кот"` → `False`: регистр учитывается. Для символов на конкретной позиции используют `text1[i] == text2[i]`. Если длины строк различаются, нужно заранее учитывать возможный `IndexError`. Для сравнения без учёта регистра можно использовать `text1.lower() == text2.lower()`. Оператор `is` для проверки равенства текста не используют.

**`text.isdigit()` — проверка цифровых символов (разобрали).** Вызывается с пустыми скобками, поскольку дополнительных аргументов не нужно. Возвращает `True`, если строка непустая и каждый символ — цифровой: `"123".isdigit()` → `True`; `"12 3".isdigit()`, `"-12".isdigit()`, `"12.5".isdigit()` и `"".isdigit()` → `False`. **Не равнозначно** проверке возможности преобразовать строку через `int()`: некоторые Unicode-цифры проходят `isdigit()`, но не подходят для `int()`.

**`text.strip(chars=None)` — убрать символы с краёв (разобрали).** Без аргументов удаляет пробелы, табуляции и переводы строк **в начале и конце**: `"  Имя  ".strip()` → `"Имя"`; `"  ".strip()` → `""`. Пробелы **внутри** строки сохраняются. `"--имя--".strip("-")` → `"имя"`. Аргумент `chars` — набор символов для удаления с обоих краёв, а не подстрока. Метод возвращает новую строку. Проверка `if not name.strip():` выявляет пустое или состоящее только из пробельных символов название.

**Почему после методов пишут `()` (разобрали).** `text.isdigit` — ссылка на метод; `text.isdigit()` — его вызов и получение `True` или `False`. Методы `.lower()`, `.upper()`, `.strip()`, `.isdigit()` можно вызывать без аргументов, а `.find(" ")` и `.remove(20)` требуют аргумент. Не путать вызов метода с круглой записью кортежа `(10, 20)`.

**`items.remove(value)` — удалить значение из списка (разобрали).** Удаляет **первое** совпадение и изменяет сам список:

```python
items = [10, 20, 30, 20]
items.remove(20)
print(items)  # [10, 30, 20]
```

Если значения нет, возникает `ValueError`. Метод возвращает `None`, поэтому `items = items.remove(20)` — ошибка в логике: вместо списка переменная получит `None`. `remove()` — метод **списка**, не строки и не кортежа.

**`items.pop(index=-1)` — удалить по индексу и вернуть элемент (ознакомились).** `items = [10, 20, 30]; x = items.pop(1)` удалит `20`, вернёт его в `x`, а список станет `[10, 30]`. Без аргумента удаляет последний элемент. Неверный индекс или вызов на пустом списке приводит к `IndexError`. Главное отличие: `remove(20)` ищет **значение**, а `pop(1)` использует **индекс**.

**`tuple` — кортеж (разобрали).** `point = (10, 25)` хранит упорядоченные элементы; `point[0]` → `10`. В отличие от списка `[]`, элементы кортежа нельзя заменить, добавить или удалить обычными методами списка: `point[0] = 5` вызовет `TypeError`. Повторяющиеся значения разрешены, типы могут отличаться. Для одного элемента нужна запятая: `(10,)` — кортеж, `(10)` — число. Внутри кортежа могут находиться изменяемые объекты, например списки; неизменяемость кортежа не делает вложенные списки неизменяемыми.

**Состояние освоения:** `.isdigit()`, `.strip()`, `.remove()`, кортежи, сравнение символов и индексацию **разобрали**, но не отмечаем автоматически как закреплённые самостоятельными заданиями. `.pop()` показали для сравнения с `.remove()`; подробное изучение списков ещё впереди.


### 4.3. Последовательности и преобразования


**`map(function, iterable)` — применить функцию к элементам (ознакомились).** `map(int, ["5", "10", "-3"])` создаёт **итератор**, выдающий числа при переборе. Чтобы увидеть все значения как список: `list(map(int, ["5", "10", "-3"]))` → `[5, 10, -3]`. Обратите внимание: `int` передаётся **без круглых скобок** — `map(int, ...)`, не `map(int(), ...)`. Итератор `map` обычно одноразовый; повторное преобразование уже полностью пройденного итератора в список даст пустой список. Если встретится `"abc"`, `int` вызовет `ValueError` при обработке этого элемента.

**Совместная работа `split()` + `map()` + `min()` (ознакомились):**

```python
text = "15 8 -4 20"
parts = text.split()              # ['15', '8', '-4', '20'] — строки
numbers = list(map(int, parts))  # [15, 8, -4, 20] — числа
print(min(numbers))              # -4
```

Если строка пустая или содержит только пробелы, `split()` вернёт пустой список, а `min()` без `default` вызовет `ValueError`.

### 5.1. `def`: объявление и вызов

| Конструкция | Для чего | Пример |
|---|---|---|
| `def name():` | Объявить функцию | `def greet():` |
| `name()` | Выполнить функцию | `greet()` |
| `def f(a, b):` | Определить параметры | `def add(a, b):` |
| `f(2, 3)` | Передать позиционные аргументы | `add(2, 3)` |
| `f(b=3, a=2)` | Передать именованные аргументы | `add(b=3, a=2)` |
| `def f(a, b=1):` | Значение параметра по умолчанию | `f(5)` |

```python
def greet(name="Гость"):
    print("Привет,", name)

greet("Антон")  # Привет, Антон
greet()          # Привет, Гость
```

**Объявление не вызывает функцию.** Тело выполняется при вызове. Обязательные параметры ставят перед параметрами со значением по умолчанию.

### 5.2. `return`, `print()`, `None`

| Выражение | Действие |
|---|---|
| `print(value)` | Показать значение, не возвращая его как результат функции |
| `return value` | Вернуть значение и сразу завершить функцию |
| `return a, b` | Вернуть кортеж из двух значений |
| Отсутствует `return` | Неявно возвращается `None` |

```python
def calculate(a, b):
    return a + b, a - b

summation, difference = calculate(10, 4)
print(summation)  # 14
print(difference) # 6
```

После выполненного `return` следующие строки тела функции не выполняются. `return` может находиться в разных ветвях `if`.

### 5.3. Локальные и глобальные имена

```python
number = 10

def show():
    number = 20  # локальное имя
    print(number)

show()        # 20
print(number) # 10
```

Функция может читать глобальное имя, если оно не перекрыто локальным. `global number` разрешает переназначать глобальное имя, но для обычной логики предпочтительнее передавать данные параметрами и возвращать результат через `return`.

### 5.4. Изменяемые и неизменяемые объекты

| Действие внутри функции | Влияет на переданный объект? |
|---|---|
| `data.append(40)` для списка | Да, изменяет тот же список |
| `data[0] = 999` для списка | Да, изменяет элемент того же списка |
| `data += [40]` для списка | Да, расширяет тот же список |
| `data = [100, 200]` | Нет, локальное имя ссылается на новый список |
| `number += 5` для `int` | Нет, локальное имя получает новое значение |

**Изменяемые:** `list`, `dict`, `set`. **Неизменяемые:** `int`, `float`, `str`, `bool`, `tuple` (но вложенный в кортеж список может изменяться).

```python
def change(data):
    data.append(40)
    data = [100, 200]

numbers = [10, 20, 30]
change(numbers)
print(numbers)  # [10, 20, 30, 40]
```

### 5.5. `*args` и `**kwargs`

| Синтаксис | При объявлении | При вызове |
|---|---|---|
| `*` | `*args` собирает позиционные аргументы в `tuple` | `f(*numbers)` распаковывает коллекцию |
| `**` | `**kwargs` собирает именованные аргументы в `dict` | `f(**values)` распаковывает словарь |

```python
def report(*args, **kwargs):
    print(args)
    print(kwargs)

report(10, 20, name="Мышь")
# (10, 20)
# {'name': 'Мышь'}
```

Имена `args` и `kwargs` — соглашение, значимы именно звёздочки. При распаковке словаря ключи должны соответствовать именам параметров, если функция не принимает `**kwargs`.

### 5.6. Передача функции как аргумента

```python
def double(number):
    return number * 2

def process(value, operation):
    return operation(value)

print(process(5, double))  # 10
```

`double` — ссылка на функцию; `double(5)` — вызов функции.

### 5.7. Документирование: `docstring`, `__doc__`, `help()`

```python
def calculate(price, quantity):
    """Возвращает стоимость товара."""
    return price * quantity

print(calculate.__doc__)  # Возвращает стоимость товара.
```

`docstring` располагают первым выражением в теле функции. В отличие от комментария `#`, её можно получить через `.__doc__` и `help()`.

### 5.8. Аннотации типов

```python
def calculate(price: float, quantity: int) -> float:
    return price * quantity
```

- `price: float`, `quantity: int` — ожидаемые типы параметров.
- `-> float` — ожидаемый тип возвращаемого значения; `-> None` — содержательное значение не ожидается.
- **Аннотации не обеспечивают проверку типов во время выполнения.** VS Code/Pylance и другие анализаторы могут предупреждать о несоответствии.
- Пример: `calculate("100", 3)` вернёт строку `"100100100"`, хотя аннотация обещает `float`.

### 6.2. Частые ловушки

| Ошибка | Правило |
|---|---|
| `" 75 ".isdigit()` → `True` | На самом деле `False`; сначала `.strip()` |
| `items = items.remove(20)` | `.remove()` меняет список и возвращает `None` |
| `print()` вместо `return` | Вывод на экран не равен возврату результата |
| `data = [...]` вместо изменения списка | Присваивание меняет ссылку локального имени |
| `number += 1` с `int` | Не изменяет объект, на который ссылается внешняя переменная |
| Аннотация `-> int` гарантирует `int` | Нет, это подсказка анализатору типов |
| `*args` — список | Нет, это кортеж |
| `**kwargs` — кортеж | Нет, это словарь |
