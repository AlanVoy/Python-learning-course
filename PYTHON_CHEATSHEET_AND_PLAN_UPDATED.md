## 1. Уже встречалось в наших уроках

> **Статусы:** «практиковали» — встречалось в решённых упражнениях; «разобрали» — объяснялось в беседе; «ознакомились» — пример показан, но самостоятельное закрепление не подтверждено. Объяснения ниже являются справочником, а не отметкой о сдаче темы.

### Ввод, вывод, переменные и типы

| Синтаксис | Назначение | Пример |
|---|---|---|
| `print(x)` | Вывести значение | `print("Привет")` |
| `input("Подсказка: ")` | Получить строку от пользователя | `name = input("Имя: ")` |
| `int(text)` | Преобразовать строку с целым числом в `int` | `age = int(input("Возраст: "))` |
| `str(x)` | Преобразовать значение в строку | `str(42)` |
| `type(x)` | Узнать тип значения | `type(42)` |
| `x = value` | Присвоить значение переменной | `count = 0` |
| `x += 1` / `x -= 1` | Увеличить/уменьшить значение | `count += 1` |
| `text += "!"` | Дописать строку справа | `text = "Привет"; text += "!"` |
| `del x` | Удалить имя переменной | `del count` |

**Важно:** `input()` возвращает `str`; `int(input())` может вызвать `ValueError`, если введено не целое число. Присваивание `=` не то же самое, что сравнение `==`.

### Числа и операции

| Синтаксис | Что делает | Пример / результат |
|---|---|---|
| `+`, `-`, `*` | Сложение, вычитание, умножение | `2 * 3` → `6` |
| `/` | Обычное деление | `7 / 2` → `3.5` |
| `//` | Деление с округлением вниз | `7 // 2` → `3` |
| `%` | Остаток от деления | `7 % 2` → `1` |
| `**` | Возведение в степень | `2 ** 3` → `8` |
| `abs(x)` | Модуль числа | `abs(-7)` → `7` |
| `min(a, b)`, `max(a, b)` | Минимум и максимум | `max(4, 9)` → `9` |

Для положительного целого числа `n`: `n % 10` получает последнюю цифру; `n // 10` убирает последнюю цифру. Для отрицательных чисел сначала часто используют `abs(n)`, если по условию нужно работать с цифрами без знака.

| Синтаксис | Что делает |
|---|---|
| `len(text)` | Длина строки |

| `text.find(part, start)` | Найти индекс подстроки, начиная с `start` |

### Условия и логика

```python
if age < 0:
    print("Некорректный возраст")
elif age >= 18:
    print("Совершеннолетний")
else:
    print("Несовершеннолетний")
```

| Синтаксис | Значение |
|---|---|
| `==`, `!=` | Равно, не равно |
| `<`, `<=`, `>`, `>=` | Сравнения |
| `and` | Оба условия истинны |
| `or` | Хотя бы одно условие истинно |
| `not` | Логическое отрицание |
| `True`, `False` | Логические значения |

`if`, `elif`, `else`, `while` и `for` заканчиваются двоеточием `:`; тело блока выделяется отступом. После `else` **нельзя** писать условие (`else x > 0:` — ошибка); для условия нужен `elif`.

### Цикл `while`

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

- `while условие:` — повторяет тело, пока условие истинно.
- `break` — немедленно завершает ближайший цикл.
- `continue` — переходит к следующей итерации ближайшего цикла (для `while` важно не забыть обновлять переменные, иначе возможен бесконечный цикл).
- **Итерация** — один проход тела цикла.
- **Счётчик** считает события или повторы; **накопитель** хранит сумму; **флаг** (`True`/`False`) фиксирует обнаруженный факт.
- `while True:` — бесконечный цикл, если не предусмотреть выход.

### Завершение программы

```python
import sys

if attempts >= 3:
    print("Попытки закончились")
    sys.exit()
```

`break` выходит **только из цикла**, а не из всей программы. `sys.exit()` инициирует завершение программы через исключение `SystemExit`; в обычном скрипте это приводит к завершению, если исключение не перехвачено. `return` применяется внутри функции — функции ещё предстоит изучить системно.

### `for` и `range()` — знакомимся сейчас, тема НЕ закрыта

```python
for i in range(2, 10, 2):
    print(i)
```

Результат: `2`, `4`, `6`, `8`. Форма `range(start, stop, step)`: `start` включается, `stop` **не включается**, `step` задаёт шаг. `range(5)` даёт `0, 1, 2, 3, 4`; `range(2, 5)` даёт `2, 3, 4`. `step` не может быть нулём; отрицательный шаг возможен, но ещё требует закрепления.

`i` — обычная переменная, а не специальная команда. На каждой итерации `for` **присваивает** ей очередное значение, не прибавляя его к предыдущему. После цикла `i` обычно сохраняет последнее присвоенное значение; если цикл ни разу не выполнялся и переменной раньше не было, она не создастся. Цикл `for` не создаёт отдельную область видимости.

Пример для самостоятельного разбора (не приводим ответ, пока ты решаешь):

```python
i = 10
for i in range(2, 5):
    i += 10
print(i)
```

## 1А. Подробные инструкции по использованию синтаксиса

Этот раздел дополняет краткие таблицы выше. В примерах имена `x`, `text`, `numbers` — обычные переменные, которые можно переименовывать.

### Ввод, вывод и преобразование типов

**`print(*values, sep=" ", end="\n")` — вывод на экран (практиковали).** В скобках указывают одно или несколько значений через запятую. По умолчанию между ними ставится пробел (`sep=" "`), а в конце — перевод строки (`end="\n"`). `sep` и `end` задаются именованными аргументами. Например:

```python
position = 3
print("Позиция", position, ":", sep="")  # Позиция3:
print("Позиция ", position, ":", sep="")  # Позиция 3:
print("Готово", end="!")                  # Готово!
```

**`input(prompt)` — ввод (практиковали).** Выводит необязательную подсказку и ожидает ввод пользователя. Результат **всегда `str`**, даже если введено `123`. Пример: `name = input("Имя: ")`.

**`int(value)` — преобразование в целое число (практиковали).** `int("25")` даёт `25`; `int("-3")` даёт `-3`. `int("2.5")` и `int("привет")` вызывают `ValueError`. `int(2.9)` даёт `2` (отбрасывает дробную часть по направлению к нулю). Для чтения числа: `age = int(input("Возраст: "))`.

**`str(value)` — преобразование в строку (практиковали).** Например, `str(25)` даёт `"25"`. Нужно, если соединяем число с текстом оператором `+`: `"Возраст: " + str(age)`.

**`type(value)` — тип объекта (практиковали).** `type(25)` — `<class 'int'>`, `type("25")` — `<class 'str'>`. Полезно при отладке; `type(x)` не преобразует значение.

**`list(iterable)` — создать список из перебираемого объекта (ознакомились).** `list(map(int, ["1", "2"]))` даёт `[1, 2]`; `list("кот")` даёт `['к', 'о', 'т']`. Список — отдельная структура данных, которую будем изучать подробно позже.

### Переменные и операторы

**`name = value` — присваивание (практиковали).** Запоминает ссылку на значение под именем `name`. `x = 10`, затем `x = 20` заменяет прежнее значение имени; `=` не сравнивает значения.

**`+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=` — составные присваивания.** `x += 3` означает увеличение `x` на 3; `x *= 2` — умножение на 2. С числами работали неоднократно. Со строками `text += "!"` соединяет строки; `text += 3` вызовет `TypeError`.

**`del name` — удаление имени (разобрали).** После `x = 5; del x` обращение к `x` вызовет `NameError`, если имя не было создано заново. Можно `del a, b`. Обычно вручную удалять локальные переменные не требуется; `del` не гарантирует немедленного освобождения памяти.

**Числовые операторы (практиковали):** `+` сумма, `-` разность, `*` произведение, `/` обычное деление (результат `float`), `//` деление с округлением вниз, `%` остаток, `**` степень. Например, `-7 // 2 == -4` (не `-3`), `-7 % 2 == 1`. Деление на ноль (`/`, `//`, `%`) вызывает `ZeroDivisionError`. Скобки `()` управляют порядком действий.

**`abs(number)` — модуль числа (практиковали).** `abs(-15)` даёт `15`; `abs(15)` — `15`. Часто нужен для обработки цифр отрицательного целого числа без учёта знака.

**`min(...)` и `max(...)` — минимум и максимум (практиковали / разобрали).** Можно передать несколько отдельных значений (`min(3, -1, 8)`) или одну непустую коллекцию (`max([3, 8, 1])`). Сравнение строк — лексикографическое, а не числовое: `min("9", "10")` не является поиском минимального числа. Для пустого списка `min([])` возникает `ValueError`; `min([], default=0)` вернёт `0`. Для чисел из строки сначала требуется преобразование в `int`.

### Строки: методы и форматирование

**`len(value)` — длина (практиковали).** `len("кот")` даёт `3`; `len("a b")` даёт `3`, потому что пробел тоже символ. Работает также со списками и другими коллекциями; не работает непосредственно с `int`.

**`text.upper()` / `text.lower()` — регистр (практиковали).** Возвращают новую строку с верхним/нижним регистром: `"PyThOn".lower()` → `"python"`. Исходная строка не меняется, если не присвоить результат: `text = text.lower()`.

**`text.split(sep=None, maxsplit=-1)` — разбить строку (ознакомились).** Без аргументов разбивает по любым последовательностям пробельных символов и не создаёт пустые элементы на краях: `"  10   20  ".split()` → `["10", "20"]`. С явным разделителем: `"a,b,c".split(",")` → `["a", "b", "c"]`. `"a  b".split(" ")` → `["a", "", "b"]`: повторные пробелы здесь дают пустой элемент. `maxsplit=1` ограничивает количество разделений: `"a b c".split(maxsplit=1)` → `["a", "b c"]`. Результат — **список строк**, а не чисел.

**`text.replace(old, new, count=-1)` — заменить подстроку (разобрали).** `"a b c".replace(" ", "")` → `"abc"`; `"кот-кот".replace("кот", "пёс", 1)` → `"пёс-кот"`. Возвращает новую строку, не изменяя исходную. Если требуется убрать обычные пробелы, `replace(" ", "")` удалит именно их, а не все виды пробельных символов.

**`text.find(sub, start=0, end=...)` — найти позицию подстроки (разобрали).** `"12 345 67".find(" ", 3)` → `6`. Индексация начинается с нуля; `start` включается, `end` (если указан) исключается. Если совпадение не найдено, возвращает `-1`. Для поиска после определённой позиции: `text.find(" ", position + 1)`. Метод ищет **символы**, а не числовые значения.

**`f"...{expression}..."` — f-строка (разобрали).** Подставляет результат выражения внутрь текста: `position = 3; print(f"Число на позиции {position}:")` → `Число на позиции 3:`. Пробелы пишутся вручную там, где нужны. Можно вставлять выражения: `f"Сумма: {2 + 3}"`. Для буквальных фигурных скобок пишут `{{` и `}}`.

**`a + b` и `text += suffix` — соединение строк (практиковали / разобрали).** `"Привет" + "!"` → `"Привет!"`; `text += "!"` присваивает переменной новую соединённую строку. Строки неизменяемые; операторы не редактируют символы внутри прежнего объекта.

### Преобразование последовательностей

**`map(function, iterable)` — применить функцию к элементам (ознакомились).** `map(int, ["5", "10", "-3"])` создаёт **итератор**, выдающий числа при переборе. Чтобы увидеть все значения как список: `list(map(int, ["5", "10", "-3"]))` → `[5, 10, -3]`. Обратите внимание: `int` передаётся **без круглых скобок** — `map(int, ...)`, не `map(int(), ...)`. Итератор `map` обычно одноразовый; повторное преобразование уже полностью пройденного итератора в список даст пустой список. Если встретится `"abc"`, `int` вызовет `ValueError` при обработке этого элемента.

**Совместная работа `split()` + `map()` + `min()` (ознакомились):**

```python
text = "15 8 -4 20"
parts = text.split()              # ['15', '8', '-4', '20'] — строки
numbers = list(map(int, parts))  # [15, 8, -4, 20] — числа
print(min(numbers))              # -4
```

Если строка пустая или содержит только пробелы, `split()` вернёт пустой список, а `min()` без `default` вызовет `ValueError`.

### Условия, логика и циклы

**`if condition:` / `elif condition:` / `else:` — ветвление (практиковали).** `if` проверяет первое условие; `elif` — следующее, если предыдущие ложны; `else` выполняется, если ни одно условие не подошло. `elif` и `else` не могут стоять сами по себе без соответствующего `if`; у `else` нет условия. После `:` идёт блок с одинаковым отступом (обычно 4 пробела).

**Сравнения:** `==` равно, `!=` не равно, `<` меньше, `<=` не больше, `>` больше, `>=` не меньше. Результат — `True` или `False`. Например, `3 <= 5` → `True`. Цепочка `0 <= age <= 120` проверяет обе границы.

**Логика:** `and` требует истинности обоих условий; `or` — хотя бы одного; `not` меняет истинность на противоположную. Например, `age >= 18 and age < 65`. Выражения `and`/`or` вычисляются с сокращением: если результат уже определён, правая часть может не вычисляться.

**`while condition:` — цикл по условию (практиковали).** Перед каждым повтором проверяет условие. Если оно сразу ложно, тело не выполняется ни разу. При счётчике не забывайте менять его, иначе возможен бесконечный цикл:

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

**`for variable in iterable:` — перебор (изучаем, тема не закрыта).** На каждой итерации присваивает переменной очередной элемент. В `for i in range(3):` значения `i`: 0, 1, 2. Изменение `i` внутри цикла не меняет следующий элемент `range()`. После цикла переменная обычно содержит последнее присвоенное значение. Если итераций не было, новое имя не появится.

**`range(stop)` / `range(start, stop[, step])` — диапазон целых чисел (изучаем).** Начало включено, конец исключён. `range(2, 7, 2)` даёт 2, 4, 6. `range(5)` даёт 0–4. `range(5, 0, -2)` даёт 5, 3, 1. Шаг `0` запрещён (`ValueError`). `range` сам по себе не список, но его можно перебирать в `for`.

**`break` — выйти из ближайшего цикла (практиковали).** Работает в `while` и `for`; при вложенных циклах завершает только внутренний. **`continue` — перейти к следующей итерации** (разобрали): пропускает оставшуюся часть тела цикла; в `while` важно не забывать обновлять условие завершения.

**`import sys` и `sys.exit()` — завершение скрипта (разобрали).** Сначала импортируют модуль `sys`, затем вызывают `sys.exit()` при необходимости. Это вызывает `SystemExit`; при обычном запуске скрипт завершается, если исключение не перехвачено. `break` в отличие от него завершает только цикл. Встроенный `exit()` встречался в коде, но для скриптов лучше `sys.exit()`.

### Полезные правила применения

1. У **метода** объект пишут перед точкой: `text.split()`, `text.find(" ")`. У **функции** объект обычно передают в скобках: `len(text)`, `min(numbers)`, `map(int, numbers)`.
2. Скобки `()` вызывают функцию или метод. В `map(int, parts)` функция `int` передаётся как значение, поэтому `()` после `int` не нужны.
3. Метод, возвращающий новую строку, не меняет исходную автоматически: `text.replace(...)` нужно сохранить в переменную, если результат нужен дальше.
4. Индексы строк и списков начинаются с `0`. Пробел — такой же символ строки, как буква или цифра.
5. Сравнивайте **числа с числами**, а не числовые строки между собой: `"10" < "2"` истинно при лексикографическом сравнении, но `10 < 2` ложно.

## 2. Типовые приёмы, которые мы уже применяли

- **Проверка входных данных:** проверить условие, сообщить об ошибке, повторить запрос при необходимости, отдельно обработать исчерпание попыток.
- **Ввод до стоп-значения:** `while` и специальное значение (часто `0`).
- **Сумма и количество:** отдельные переменные-накопители и счётчики; среднее вычислять только при ненулевом количестве.
- **Поиск минимума/максимума:** аккуратно выбрать начальное значение, особенно если возможны отрицательные числа или пустая последовательность.
- **Обработка цифр:** `abs`, `% 10`, `// 10`; отдельно продумать число `0`.
- **Соседние элементы и серии:** хранить предыдущее значение, длину текущей серии и лучший результат; обрабатывать конец последовательности.
- **Граничные случаи:** ноль, отрицательные числа, минимум допустимых вводов, повторяющиеся значения, первый/последний элемент.
